# 🌸 Bloom Brawl（ブルームブロウル）

スマホのブラウザで遊べる、明るいパステルカラーの世界で戦う対戦アクションゲーム。

## 特徴
- 📱 **スマホ最適化** — バーチャルスティック＋アクションボタンのタッチ操作
- 🎨 **独自要素「ブルーム（開花）バトル」** — 地面を自分の色で塗りながら戦い、塗った面積（縄張り）が広いほどステータスが強化される。相手のエリアを上書きして奪い合う陣取り×アクションのハイブリッド
- 🤖 **AI対戦** — 強さの異なるCPUと対戦
- 👥 **フレンド対戦** — 同じ端末でのパスアンドプレイ対戦
- 🌈 **可愛くて明るいデザイン** — パステル＆キャンディカラー。暗いネオン系は一切なし

## 遊び方
1. ブラウザで `index.html` を開く
2. モードを選ぶ（AI対戦 / フレンド対戦 / 練習）
3. 左下のスティックで移動、右下のボタンで攻撃・ダッシュ・必殺

## 技術
- 単一HTML + Canvas + バニラJavaScript（ビルド不要・即起動）
- PC（マウス/キーボード）でもプレイ可能

## ローカルで動かす
```bash
python3 -m http.server 8000
# → http://localhost:8000
```
